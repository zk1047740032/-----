# 波形反馈调平

## 桌面波形评价

在 Windows 上从项目目录启动新的 PySide6 界面：

```powershell
uv run --python 3.14 --with-requirements requirements-frontend.txt python -B waveform_qt.py
```

控制面板标题右侧的「模拟」开关默认关闭。开启后，「开始」逐工况生成波形并评价，先扫描同一重频下的脉宽，再步进重频。「单次评价」使用起始重频和脉宽。「停止」结束扫描，清空当前波形和进度。Qt 界面默认红蓝高度允许偏差为 ±7%，原始不平度须严格小于 20%。

模拟波形来自随程序附带的示波器采集片段，覆盖 50–150 kHz、100–800 ns 范围内的 156 个工况。样本按实测半高宽核对。缺少同工况样本时，按最接近的重频和脉宽选取片段，根据设定重频排布脉冲，必要时伸缩平顶。150 kHz 以上同样使用实测范围边界的波形作近似。

模拟模式关闭时，输入示波器 IP 后点击「连接」。在示波器上启用 Socket Server（Protocol 设为 None，端口 4000），开启 CH2 并运行普通采样。程序查询型号后，通过 `WAVFRM?` 实时读取 CH2 的完整采样记录，支持最多 100 万点。时基、量程和触发由示波器面板设置。模拟模式开启时，「连接」用于核对通信和设备型号。

实时图默认放大最靠近触发时刻的完整脉冲，保留两侧基线。没有识别到完整脉冲时显示采样记录。图下方显示示波器的水平标度和 CH2 垂直标度，例如 `40 ns/格` 和 `100 mV/格`。实时图的电压范围跟随 CH2 的每格电压、垂直位置和偏置，波形幅度变化时保持同一电压范围。可在图上缩放和拖动，点击「重置缩放」恢复单脉冲视图和当前 CH2 电压范围。

首次显示波形后，点击「单次评价」固定界面当前帧，按当前阈值评价该帧的完整采样记录。评价结果显示代表脉冲，以其上升沿 50% 交点为时间零点，两侧各保留约 18% 半高宽的基线，并沿用该帧的 CH2 电压范围。评价图上的「重置缩放」回到代表脉冲视图。点击「恢复」后，程序回到相对触发时刻的实时视图并显示最新波形。固定和恢复在软件界面完成，示波器可持续采集。打开本地波形文件或切回模拟模式会结束实时连接。

脉冲板口的「刷新」重新列出可用串口。选择 COM 口后点「连接」，程序以 115200、8N1 打开串口。点「断开」释放。协议只列出了设置指令，串口打开时程序不发送指令。

关闭模拟并连接脉冲板后，点击右侧「设置」可下发 y0、y1、y2，`index_d` 固定为程序值 120。双字节字段暂按 [1100 通信协议的发送示例](docs/1100通信协议.md#4-设置内外调制重频脉宽)采用高字节在前。程序核对 `0x32` 应答的帧格式、校验和回读值。字节序、板卡允许的 y 值范围和实际输出待实机确认。

脉冲板驱动也提供 `set_timing_raw()` 和 `set_shape_raw()`，接收按线序排列的双字节寄存器值。重频和脉宽的界面下发还需确认寄存器单位和 `save_flag` 的不保存取值。

点击「打开波形文件」选择 CSV 或 NPZ，即可用当前阈值对所选文件评价一次。程序从波形数据识别脉冲。模拟评价、文件评价和示波器单次评价的结果显示在界面和运行日志中。

「截图目录」用于[全自动调整流程](docs/完整流程.md#全自动调整)中保存达标工况的示波器截图。当前 Qt 版支持手动设置 y 值和评价，全自动调整与截图待接入。

## 使用

1. 双击 `方波评价.exe`，点「打开起始波形」选择示波器的 CSV 或 NPZ。选窗和评价直接从时间、电压计算。
2. 先看四区和保持期。红框对应 y0 左肩、y1 平顶前段和 y2 平顶中段。蓝框提供本脉冲的参考高度。界面默认展示代表脉冲，可以切换脉冲或定位最大不平度。自动窗需要修正时，在图上拖动起止位置并开始新一轮。
3. 如果程序给出试调或回退，只改屏幕所示的一个 y，步长为 10。采集新波形，再点对应的「已试调」或「已回退」按钮。程序要求复采时，保持设置并载入另一份新采集。确认执行后若选错文件，直接载入本步新采集。
4. 需要调整允许值时，修改「红蓝高度允许偏差」或「保持期不平度上限」，点「应用阈值」按原窗口重新判定。每步复评完成后便可应用新值。点「保存记录」可导出阈值、四区测量、采集路径、相对起点的 y 偏移和本轮最佳观测。

## 判定与复评

- 以脉冲的两个 50% 交点建立相位。y0 左肩按标注图取相位 4%–12.5%，到 y1 起点为止，独立于保持期定位。自动保持期到蓝框右侧结束，用于计算原始不平度。四区位置根据标注图暂定，同轮锁定窗口。蓝框高度在每个脉冲上重新测量。
- 各区高度取扣基线后的中位数。红蓝偏差为 `(红框高度−蓝框高度)/蓝框高度`，每个完整脉冲的三个偏差均须落在 **±允许偏差** 内，默认 **7%**。程序选同向证据足够且超限较多的区，建议一步 ±10。
- 功率不平度按保持期内全部扣基线的原始样点计算 `(最大值−最小值)/平均值`。每个完整脉冲都须严格低于上限，默认 **15%**。两项都满足才显示达标。红蓝已对齐但不平度超限时保持 y，提示检查区内和框间波形。
- 每轮默认最多 12 次试调，每步最多 2 次额外复采。改参后按锁定窗口比较红蓝偏差、最差脉冲和整段不平度。变化与复采波动重合时先复采，退化时按一步回退。最佳观测优先保留两项达标的波形，再看最大红蓝偏差、不平度和最差脉冲 RMS。

## 验证

- 认可的 `150ns.csv` 有 10 个完整脉冲。新版选窗下最大红蓝偏差为 **6.78%**，最大不平度为 **15.11%**。默认阈值下红蓝对齐，整体指标仍超限，三个 y 保持。以 **7% / 16%** 重判可达标，两个实测分数保持原值。
- 合成回放覆盖三轴方向、同窗复评、可调阈值、边界值、复采与回退。可执行 `uv run --python 3.14 --with-requirements requirements.txt python -B -m unittest discover -s tests -v` 重跑。

## 接口

CSV 支持 `time_s,voltage_v` 两列和带 s/V 元数据的 `TIME,CH2` 示波器格式。NPZ 包含一维数组 `time_s` 和 `voltage_v`。

`evaluate_waveform()` 和 `run_leveling()` 传 `alignment_tolerance_pct` 启用四区评价，`raw_limit_pct` 设置不平度上限。命令行参数为 `--alignment-tolerance` 和 `--raw-limit`。当前 Windows 程序由操作员执行调参并导入新采集。设备自动化由外部控制器提供边界、确认应答和新采集接口，实际通信仍需现场联调。
