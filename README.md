# 波形反馈调平

## 使用

1. 双击 `方波评价.exe`，点「打开起始波形」选择示波器的 CSV 或 NPZ。选窗和评价直接从时间、电压计算。
2. 先看保持期和功率不平度。界面默认展示代表脉冲，可以切换脉冲或定位最大不平度。自动窗需要修正时，在图上拖动起止位置并开始新一轮。
3. 如果程序给出试调或回退，只改屏幕所示的一个 y，步长为 10。采集新波形，再点对应的「已试调」或「已回退」按钮。程序要求复采时，保持设置并载入另一份新采集。确认执行后若选错文件，直接载入本步新采集。
4. 程序保留本轮每次采集的路径、分数、相对起点的 y 偏移和本轮最佳观测。点「保存记录」可导出 JSON。请保留对应的 CSV 或 NPZ 供复核。

## 判定与复评

- 以脉冲的两个 50% 交点建立相位，用两侧的斜率定位保持期。逐脉冲复核，同轮比较沿用起始波形的窗口。出现无法消歧的脉冲片段时，需要更清楚的波形。
- 功率不平度按窗口内扣基线后全部原始样点的 `(最大值−最小值)/平均值` 计算，严格小于 15% 才达标。暂定形状停止条件参考用户已认可的 `150ns.csv`，同时看分块 RMS、局部和原始点偏离。区域判断取每条波形自己的平顶电平。y0 对应肩部，y1 对应平顶前段，y2 对应中段。
- 达到暂定形状停止条件时，三个 y 保持。原始 15% 指标继续显示。本轮比较检查共同窗口内的中位数和最差脉冲，以及原始不平度。清楚的改善可保留，变差则按一步回退，变化与同设置复采波动重合时先复采。可辨认的区域响应参与本轮下一步判断。
- 每轮默认最多 12 次试调，每个待决步骤最多 2 次额外复采。仍没有改善证据时给出回退或停止。最佳观测按原始指标是否达标、形状是否符合停止条件、最差脉冲 RMS 和 RMS 中位数排序。

## 验证

- 认可的 `150ns.csv` 有 10 个完整脉冲，软件保持三个 y，原始最大不平度仍报告为 20.53%。另有一份 100 脉冲的实测波形，程序检出 2 个不低于 15% 的脉冲。
- 重新读取 6 份用户复核过选窗的文件，共 410 个完整脉冲。原先查看的 6 个脉冲重现各自边界，同文件共同窗与这 6 个边界的最大差为 1.54 ns。
- 回放 19 份扰动和 15 份同工况复采。可与历史同轴邻档比较的 5 个首步建议中，4 个邻档的同窗 RMS 较低，1 个略高。这个对照使用历史文件，现场效果需由每次调整后的新采集验证。
- 合成回放覆盖三轴正反方向、持续改善、噪声复测、最差脉冲退化、回退、采样条件变动、选错旧文件和下发中断。可执行 `uv run --python 3.14 --with-requirements requirements.txt python -B -m unittest discover -s tests -v` 重跑。

## 接口

CSV 支持 `time_s,voltage_v` 两列和带 s/V 元数据的 `TIME,CH2` 示波器格式。NPZ 包含一维数组 `time_s` 和 `voltage_v`。

`fiber1100_algorithm.evaluate_waveform(time_s, voltage_v)` 直接评价单次采集。`run_leveling()` 提供自动化入口，由调用方提供已确认的 y 范围、初始设置、下发应答和新采集接口。当前 Windows 程序由操作员执行调参并导入采集，已验证算法与模拟控制器。脉冲板、示波器的实际通信及复测间隔仍需现场联调。
