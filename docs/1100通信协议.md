# 脉冲激光器通信协议

上海频准激光科技股份有限公司

## 一、通信物理层

- 接口：RS422
- 波特率：115200
- 数据位：8
- 校验位：none
- 停止位：1
- 连续两条指令时间间隔：>200 ms

## 二、通信格式

| 帧格式 | 帧头     | 主机地址 | 从机地址 | 命令字 | 参数长度 | 参数 | 和校验                                   | 异或校验                                   | 结束符 | 结束符 |
| ------ | -------- | -------- | -------- | ------ | -------- | ---- | ---------------------------------------- | ------------------------------------------ | ------ | ------ |
| 内容   | `0x50` | `0x00` | `0x00` | A      | B        | C    | 从主机地址开始至参数止，所有字节的和校验 | 从主机地址开始至参数止，所有字节的异或校验 | `\r` | `\n` |
| 字节数 | 1        | 1        | 1        | 1      | 1        | 0–N | 1                                        | 1                                          | 1      | 1      |

## 三、指令

### 1. 查询激光器工作状态

实际上，激光器自主向外发送 `A=0x44` 的返回指令，无需用户主动发送查询。

发送：`A=0x04`，`B=0x00`，没有 C。

示例：

```text
50 00 00 04 00 04 04 0D 0A
```

返回：`A=0x44`，`B=0x40`，C 内容为：

| 寄存器                 | 字节数 | 说明                                        |
| ---------------------- | -----: | ------------------------------------------- |
| 备用                   |      1 |                                             |
| 备用                   |      1 |                                             |
| `flag_system_status` |      2 | 高低 8 位组成 16 位无符号数，系统状态寄存器 |
| `Driver_unlock`      |      1 | 激光器使能寄存器                            |
| 备用                   |      2 |                                             |
| `ISET_RT[0]`         |      2 | 激光器一级工作电流                          |
| 频率                   |      3 | 激光器的重复频率                            |
| 脉宽                   |      2 | 激光器的脉宽                                |
| `ISET_RT[1]`         |      2 | 激光器二级工作电流                          |
| 备用                   |      3 |                                             |
| 备用                   |      2 |                                             |
| `ISET_RT[2]`         |      2 | 激光器三级工作电流                          |
| 备用                   |      3 |                                             |
| 备用                   |      2 |                                             |
| `PD_SNS_VALUE[0]`    |      2 | PD1 采样值                                  |
| `PD_SNS_VALUE[1]`    |      2 | PD2 采样值                                  |
| `PD_SNS_VALUE[2]`    |      2 | PD3 采样值                                  |
| `PD_SNS_VALUE[3]`    |      2 | PD4 采样值                                  |

| `PD_status[1]`       |      1 | PD2 参数状态                                |

### 2. 使能激光器

发送：`A=0x30`，`B=0x01`，`C=0x07`。

示例：

```text
50 00 00 30 01 07 38 36 0D 0A
```

返回：`A=0x40`，`B=0x0D`，`C="Enable set ok"`。

示例：

```text
50 00 00 40 0D 45 6E 61 62 6C 65 20 73 65 74 20 6F 6B FA 0A 0D 0A
```

### 3. 设置激光器工作电流

50 00 00 A1 02 00 64 07 C7 0D 0A  (设置电流 1A)

### 4. 设置内外调制、重频、脉宽

发送：`A=0xAA`，`B=0x09`，C 为：

| 字段                                 | 字节数 |
| ------------------------------------ | -----: |
| 保存标志（`0x00`、`0x01`）       |      1 |
| 内外调制标志位（`0x11`、`0x00`） |      1 |
| 备用                                 |      2 |
| 频率                                 |      3 |
| 脉宽                                 |      2 |

示例：

```text
50 00 00 AA 09 00 00 00 00 00 01 F4 00 96 3E C0 0D 0A
```

频率 500，脉宽 150。

返回示例：

```text
50 00 00 41 2D 00 00 C8 00 00 00 01 F4 00 02 58 00 96 00 C8 00 02 58
00 00 00 27 10 00 00 00 01 F4 00 00 00 01 90 00 00 00 07 D0 00 00 00 07 D0 00 00
A8 5C 0D 0A
```

说明：需要先发一个解密指令，再发设置指令才能设置成功。

```text
50 00 00 8C 08 31 32 33 34 35 36 37 38 38 8C 0D 0A
```

## 四、流程

### 激光器开启

1. 开启激光器电源，等待稳定（约 5 分钟）。
2. 开始接收 `0x44` 返回指令，获得激光器运行状态信息，读取 `flag_system_status` 中报警及故障信息，无故障及报警可往下操作。
3. 设置脉宽、频率。
4. 开启使能。
5. 设置电流 1A、2A、3A……至本机最大的电流。

### 激光器关闭

1. 设置电流从当前电流以 1A 为间隔逐步降低至 0A。
2. 关闭使能。
3. 关闭电源。

## 五、寄存器说明

### `uint8 PD_status[4]`

PD1-4 的配置，各位定义如下：

| 位 | 值 | 含义                        |
| -- | -- | --------------------------- |
| D7 | 1  | 要求状态复位                |
| D6 | 1  | 数字下限保护出现，PD 值过低 |
| D5 | 1  | 数字上限保护出现，PD 值过高 |
| D4 | 1  | 硬件保护出现                |
| D3 | 1  | 数字下限保护启用            |
| D2 | 1  | 数字上限保护启用            |
| D1 | 1  | 过载输入信号启用            |
| D0 | 1  | 启用 PD；0 表示禁用 PD      |

### `uint16 flag_system_status`

系统状态，各位定义如下：

| 位  | 值 | 含义                           |
| --- | -- | ------------------------------ |
| D15 | 0  | 备用                           |
| D14 | 0  | 备用                           |
| D13 | 0  | 备用                           |
| D12 | 0  | 温度 T5 保护正常，未报警或故障 |
| D11 | 0  | 温度 T4 保护正常，未报警或故障 |
| D10 | 0  | 温度 T3 保护正常，未报警或故障 |
| D9  | 0  | 温度 T2 保护正常，未报警或故障 |
| D8  | 0  | 温度 T1 保护正常，未报警或故障 |
| D7  | 0  | PD4 值正常，未报警或故障       |
| D6  | 0  | PD3 值正常，未报警或故障       |
| D5  | 0  | PD2 值正常，未报警或故障       |
| D4  | 0  | PD1 值正常，未报警或故障       |
| D3  | 0  | 备用                           |
| D2  | 0  | 备用                           |
| D1  | 0  | 备用                           |
| D0  | 0  | 备用                           |

### `uint8 Driver_unlock`

激光器使能寄存器，各位定义如下：

| 位 | 值 | 含义                         | 写操作 |
| -- | -- | ---------------------------- | ------ |
| D7 | 1  | 备用                         | 无效   |
| D6 | 1  | Interlock 允许激光器运行标志 | 无效   |
| D5 | 1  | Driver3 已使能标志           | 无效   |
| D4 | 1  | Driver2 已使能标志           | 无效   |
| D3 | 1  | Driver1 已使能标志           | 无效   |
| D2 | 1  | 使能 Driver3                 |        |
| D1 | 1  | 使能 Driver2                 |        |
| D0 | 1  | 使能 Driver1                 |        |
