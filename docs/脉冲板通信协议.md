# 脉冲板通信协议

串口使用 115200 波特率、8 数据位、无奇偶校验、1 停止位（8N1）。

## 1. 通信帧格式

| 字段     | 内容                                         | 字节数 |
| -------- | -------------------------------------------- | -----: |
| 帧头     | `0x57`                                     |      1 |
| 主机地址 | `0x00`                                     |      1 |
| 从机地址 | `0x00`                                     |      1 |
| 命令字   | A                                            |      1 |
| 参数长度 | B                                            |      1 |
| 参数     | C                                            |    0-N |
| 和校验   | 从主机地址开始至参数结束，所有字节的和校验   |      1 |
| 异或校验 | 从主机地址开始至参数结束，所有字节的异或校验 |      1 |
| 结束符 1 | `\r`（`0x0D`）                           |      1 |
| 结束符 2 | `\n`（`0x0A`）                           |      1 |

帧结构如下：

```text
57 00 00 A B [C，共 B 字节] [和校验] [异或校验] 0D 0A
```

由上述字段长度可得，完整帧长度为 `B + 9` 字节。两个校验字段的计算范围均不包含帧头、校验字段本身及结束符。

## 2. 指令概览

下表的参数长度同时列出十进制和十六进制表示。

| 指令                             | 发送命令字 A | 发送参数长度 B | 返回命令字 A | 返回参数长度 B |
| -------------------------------- | ------------ | -------------- | ------------ | -------------- |
| 设置频率、脉宽                   | `0x22`     | 6（`0x06`）  | `0x32`     | 13（`0x0D`） |
| 设置 y0、y1、y2、index_d 参数 | `0x42`     | 8（`0x08`）  | `0x32`     | 13（`0x0D`） |

## 3. 设置频率、脉宽

### 3.1 发送

命令字：`A = 0x22`；参数长度：`B = 6`（`0x06`）。

参数 C 按下表顺序排列：

| 寄存器              | 字节数 | 说明                                            |
| ------------------- | -----: | ----------------------------------------------- |
| `new_frequency`   |      2 | 设置激光器频率                                  |
| `new_pulse_width` |      2 | 设置激光器脉宽                                  |
| `trigger`         |      1 | 设置调制方式：内调制为 0，外调制为 1            |
| `save_flag`       |      1 | 预设置是否保存数据至 EEPROM；具体取值原图未注明 |

参数总长度：`2 + 2 + 1 + 1 = 6` 字节。

### 3.2 返回

命令字：`A = 0x32`；参数长度：`B = 13`（`0x0D`）。

参数 C 按下表顺序排列：

| 寄存器              | 字节数 | 说明                                 |
| ------------------- | -----: | ------------------------------------ |
| `new_frequency`   |      2 | 设置激光器频率                       |
| `new_pulse_width` |      2 | 设置激光器脉宽                       |
| `trigger`         |      1 | 设置调制方式：内调制为 0，外调制为 1 |
| `y0`             |      2 | 原图未注明                           |
| `y1`             |      2 | 原图未注明                           |
| `y2`             |      2 | 原图未注明                           |
| `index_d`         |      2 | 原图未注明                           |

参数总长度：`2 + 2 + 1 + 2 + 2 + 2 + 2 = 13` 字节。

## 4. 设置 y0、y1、y2、index_d 参数

### 4.1 发送

命令字：`A = 0x42`；参数长度：`B = 8`（`0x08`）。

参数 C 按下表顺序排列：

| 寄存器      | 字节数 |
| ----------- | -----: |
| `y0`     |      2 |
| `y1`     |      2 |
| `y2`     |      2 |
| `index_d` |      2 |

参数总长度：`2 + 2 + 2 + 2 = 8` 字节。

### 4.2 返回

命令字：`A = 0x32`；参数长度：`B = 13`（`0x0D`）。

参数 C 按下表顺序排列：

| 寄存器          | 字节数 | 说明                                 |
| --------------- | -----: | ------------------------------------ |
| `frequency`   |      2 | 激光器频率                           |
| `pulse_width` |      2 | 激光器脉宽                           |
| `trigger`     |      1 | 设置调制方式：内调制为 0，外调制为 1 |
| `y0`         |      2 | 原图未注明                           |
| `y1`         |      2 | 原图未注明                           |
| `y2`         |      2 | 原图未注明                           |
| `index_d`     |      2 | 原图未注明                           |

参数总长度：`2 + 2 + 1 + 2 + 2 + 2 + 2 = 13` 字节。
