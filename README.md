# 波形反馈调平

## 桌面模拟评价

在 Windows 上从项目目录启动新的 PySide6 界面：

```powershell
uv run --python 3.14 --with-requirements requirements-frontend.txt python -B waveform_qt.py
```

「开始」逐工况生成波形并评价，先扫描同一重频下的脉宽，再步进重频。「单次评价」使用起始重频和脉宽。「停止」结束扫描，清空当前波形和进度，保留已保存的结果。新界面默认红蓝高度允许偏差为 ±7%，原始不平度须严格小于 20%。示波器 IP 和串口随模拟记录保存。

每次运行在保存地址下创建独立子目录。`run.json` 记录阈值、工况结果和运行状态；每个工况的 NPZ 含原始 `time_s`、`voltage_v` 和完整评价 `evaluation_json`。NPZ 可用下方的离线界面打开。

## 使用

1. 双击 `方波评价.exe`，点「打开起始波形」选择示波器的 CSV 或 NPZ。选窗和评价直接从时间、电压计算。
2. 先看四区和保持期。红框对应 y0 肩部、y1 平顶前段和 y2 平顶中段。蓝框提供本脉冲的参考高度。界面默认展示代表脉冲，可以切换脉冲或定位最大不平度。自动窗需要修正时，在图上拖动起止位置并开始新一轮。
3. 如果程序给出试调或回退，只改屏幕所示的一个 y，步长为 10。采集新波形，再点对应的「已试调」或「已回退」按钮。程序要求复采时，保持设置并载入另一份新采集。确认执行后若选错文件，直接载入本步新采集。
4. 需要调整允许值时，修改「红蓝高度允许偏差」或「保持期不平度上限」，点「应用阈值」按原窗口重新判定。每步复评完成后便可应用新值。点「保存记录」可导出阈值、四区测量、采集路径、相对起点的 y 偏移和本轮最佳观测。

## 判定与复评

- 以脉冲的两个 50% 交点建立相位。y0 从上升斜率持续放缓后开始，自动保持期到蓝框右侧结束。四区位置根据标注图暂定，同轮锁定窗口。蓝框高度在每个脉冲上重新测量。
- 各区高度取扣基线后的中位数。红蓝偏差为 `(红框高度−蓝框高度)/蓝框高度`，每个完整脉冲的三个偏差均须落在 **±允许偏差** 内，默认 **7%**。程序选同向证据足够且超限较多的区，建议一步 ±10。
- 功率不平度按保持期内全部扣基线的原始样点计算 `(最大值−最小值)/平均值`。每个完整脉冲都须严格低于上限，默认 **15%**。两项都满足才显示达标。红蓝已对齐但不平度超限时保持 y，提示检查区内和框间波形。
- 每轮默认最多 12 次试调，每步最多 2 次额外复采。改参后按锁定窗口比较红蓝偏差、最差脉冲和整段不平度。变化与复采波动重合时先复采，退化时按一步回退。最佳观测优先保留两项达标的波形，再看最大红蓝偏差、不平度和最差脉冲 RMS。

## 验证

- 认可的 `150ns.csv` 有 10 个完整脉冲。新版选窗下最大红蓝偏差为 **6.78%**，最大不平度为 **15.11%**。默认阈值下红蓝对齐，整体指标仍超限，三个 y 保持。以 **7% / 16%** 重判可达标，两个实测分数保持原值。
- 合成回放覆盖三轴方向、同窗复评、可调阈值、边界值、复采与回退。可执行 `uv run --python 3.14 --with-requirements requirements.txt python -B -m unittest discover -s tests -v` 重跑。

## 接口

CSV 支持 `time_s,voltage_v` 两列和带 s/V 元数据的 `TIME,CH2` 示波器格式。NPZ 包含一维数组 `time_s` 和 `voltage_v`。

`evaluate_waveform()` 和 `run_leveling()` 传 `alignment_tolerance_pct` 启用四区评价，`raw_limit_pct` 设置不平度上限。命令行参数为 `--alignment-tolerance` 和 `--raw-limit`。当前 Windows 程序由操作员执行调参并导入新采集。设备自动化由外部控制器提供边界、确认应答和新采集接口，实际通信仍需现场联调。
