# 示波器指令：脉冲波形自动整定

本文汇总 Fiber1100 自动整定所需的示波器指令，后续开发优先查阅本文。用途是获取实际脉冲波形，评价平顶、边沿和脉宽，为脉冲板的 y0、y1、y2 调整提供反馈。

- 来源：[仓库内的泰克编程手册](./MDO4000-B-C-MSO-DPO4000B-and-MDO3000-Oscilloscope-Programmer-Manual-Revision-A-077051009.pdf)。
- 适用范围：该手册覆盖的 MDO4000/B/C、MSO/DPO4000B、MDO3000 系列；连接后用 `*IDN?` 确认实际型号。
- 核对日期：2026-10-19。以下为手册核对结果，尚未连接实机验证。
- 本文“手册页”指正文印刷页码，“PDF 页”指阅读器从 1 开始的物理页码。例如手册 `2-96` 对应 PDF 第 126 页。
- 示例统一使用 `CH2`，与需求讨论中的截图一致；实际采集通道、触发源、量程及阈值须按现场接线配置。
- 激光频率、脉宽和 y 参数由脉冲板设置，见[脉冲板通信协议](./脉冲板通信协议.md)。不要用示波器的 `AFG:*` 指令代替脉冲板设置。

阅读顺序：首次连接及初始化查第 2、3 节；每轮整定查第 4、5、6 节；内置测量查第 7 节；异常诊断查第 8 节。

## 2. 网口连接与命令收发

手册依据：`1-11` 至 `1-15`（PDF 23-27），`2-763` 至 `2-765`（PDF 793-795），命令终止规则 `2-5`（PDF 35）。

### 2.1 Socket Server

1. 示波器与电脑接入可互通的网络，确认示波器 IP。
2. 示波器前面板进入 `Utility → Utility Page → I/O → Socket Server`，启用服务。
3. 自动化程序使用 `Protocol = None`。`Terminal` 模式会增加欢迎信息和提示符，不适合作为本文二进制解析流程的输入。
4. 端口默认 `4000`，以设备显示的 `Current Port` 为准。
5. 建立 TCP 连接，发送 `*IDN?` 并完整读取响应，确认型号及通信正常。

| 指令 | 作用 |
| --- | --- |
| `SOCKETServer:ENAble?` | 查询服务是否启用，`1` 为启用 |
| `SOCKETServer:PORT?` | 查询当前端口 |
| `SOCKETServer:PROTOCol?` | 查询 `NONE` / `TERMINAL` |
| `SOCKETServer:ENAble ON` | 启用服务 |
| `SOCKETServer:PORT 4000` | 设置端口；仅为默认端口示例 |
| `SOCKETServer:PROTOCol NONe` | 设置原始 Socket 模式 |

首次启用服务可通过前面板完成；服务尚未启用时，不能指望通过该服务发送启用指令。初始化采集时无须反复修改端口或协议。

### 2.2 收发约定

- 指令大小写不敏感，混合大小写表示手册规定的缩写边界；实现中可统一使用表中的拼写或全大写。
- 表中 `<...>` 是程序替换的参数，不能原样发送。注释、步骤说明、响应示例也不能当成指令发送。
- 设置指令通常没有文本响应；带 `?` 的查询必须读取完整响应后，再发送下一条查询。同一连接的收发应串行执行。
- 原始 Socket 客户端可从以 `LF`（`\n`）结束每条 SCPI 指令开始联调，并用 `*IDN?` 验证实际终止设置。手册未单独明确 `None` 模式下 LF/CRLF 的差异。VISA/USBTMC/GPIB 等仪器消息接口应遵循其 EOM/EOI 规则；手册 `2-5` 明确指出该仪器消息接口不支持仅以 ASCII LF 终止消息，不能混用两类传输层假设。
- 文本响应按其消息结束标记读取；二进制响应按长度读取，见第 6 节。TCP 的一次接收不保证收到完整响应。
- `HEADer OFF` 使普通查询返回值不附带 `:命令名`，便于解析。`VERBose ON` 可统一使用完整关键词；枚举响应仍应去除首尾空白并统一大小写。

## 4. 采集模式与完成同步

手册依据：`2-114` 至 `2-118`（PDF 144-148），`2-209`（PDF 239），`2-457` 至 `2-458`（PDF 487-488），`3-7` 至 `3-13`（PDF 1017-1023）。

| 指令 | 作用 |
| --- | --- |
| `ACQuire:STATE STOP` | 停止采集，便于修改参数及配置 |
| `ACQuire:MODe SAMple` | 普通采样；本项目默认分析 YT 波形 |
| `ACQuire:STOPAfter SEQuence` | 下一次 `RUN` 启动单次采集序列，完成后停止 |
| `ACQuire:STATE RUN` | 启动新采集；单次序列模式下会重新启动该序列 |
| `ACQuire:STATE?` | `0` 表示停止；非零表示采集运行 |
| `ACQuire:NUMACq?` | 查询本次启动以来的采集次数，可辅助确认采到了新数据 |
| `BUSY?` | `1` 表示仍有支持同步的长操作未完成，`0` 表示已完成 |
| `*OPC?` | 等支持 OPC 的操作结束后返回 `1`；单次序列采集属于支持的操作 |
| `ACQuire:STOPAfter RUNSTop` | 恢复连续采集模式；需要同时 `ACQuire:STATE RUN` 才会运行 |

### 4.1 每组参数对应一次新采集

首次采集前先完成第 3 节的通道、时基和触发配置，并设置 `HEADer OFF`、`VERBose ON`。下面的循环不替代这些初始化步骤。

以下是程序顺序说明，不是可原样发送的指令块：

```text
1. 发送 ACQuire:STATE STOP。
2. 向脉冲板下发当前频率、脉宽、y0/y1/y2，确认应答，等待输出稳定。
3. 如工况变化，更新示波器量程、时基和触发设置。
4. 确认 ACQuire:MODe SAMple、ACQuire:STOPAfter SEQuence。
5. 发送 ACQuire:STATE RUN。
6. 选择以下一种完成同步方式，并设置程序总超时：
   A. 逐次查询 BUSY? 并读完响应，直到为 0；轮询间留出间隔。
   B. 查询 *OPC?，完整读取返回的 1 后继续。
7. 确认本次序列正常完成；可用 STATE? = 0、NUMACq? >= 1 辅助检查。
8. 在保持停止状态下查询本次波形前导参数，再读取 CURVe?。
9. 换算、评价和记录波形；修改 y 值后从第 1 步重新开始。
```

- `BUSY?` 轮询便于在两次查询之间响应停止操作；`*OPC?` 更简单，但等待期间可能一直没有响应。两种方式不能在响应未读完时混用。
- `*OPC?` 只同步手册列出的示波器操作，不负责等待脉冲板输出或激光器稳定；板卡稳定等待在第 2 步完成。
- `BUSY? = 0` 或 `STATE? = 0` 本身不能证明新采集成功，例如用户中止也会停止。必须结合本次确已启动、没有中止/超时及采集计数判断。
- `NORMal` 触发模式下无有效触发可能永远等不到采集完成。超时或取消后，本轮数据应作废，停止采集；若仍有未完成的查询或未读完的二进制响应，先清理或重建会话，再继续查询。
- 在 `*OPC?` 超时后直接查询 `CURVe?` 可能把迟到的 `1` 误当波形开头，不能这样继续。

### 4.2 多次复测与可选平均

优先对同一组 y 参数重复执行单次采集，逐条波形评价后综合判断。若使用示波器平均模式：

```scpi
ACQuire:MODe AVErage
ACQuire:NUMAVg 16
ACQuire:STOPAfter SEQuence
ACQuire:STATE RUN
```

然后按上节等待序列完成。`NUMAVg` 支持 2-512 的 2 的幂次值。每组新参数都要重新启动序列，避免混入上一组参数的平均数据；平均波形可能掩盖逐脉冲抖动，最终验收仍需检查单次波形。

不要将 `ENVelope` / `PEAKdetect` 数据直接送入普通单值 YT 分析器；先核对 `WFMOutpre:PT_Fmt?`，`ENV` 表示最小值/最大值成对的格式。

## 5. 波形传输与前导参数

手册依据：`2-95` 至 `2-102`（PDF 125-132）、`2-270` 至 `2-281`（PDF 300-311）、`2-959` 至 `2-974`（PDF 989-1004）、附录 `D-1` 至 `D-3`（PDF 1085-1087）。

| `WFMOutpre:YZEro?` | 纵向偏置，单位与 YUNIT 相同 | `2-973` 至 `2-974`（1003-1004） |

所有查询均需单独读完响应。初版可每次采集后读取前导参数；以后若缓存，必须在通道、量程、偏置、时基、记录长度、编码、字节宽度或传输范围变化时失效。不要把一组配置下的换算参数用于另一组波形。

`SAMple` 模式本身是 8 位精度；请求 2 字节传输不会使 ADC 变成 16 位，手册说明该模式的低 8 位为零。保留 2 字节传输是为了统一数据通路，采样精度与传输宽度应分别理解。

### 5.2 时间、电压换算

对本系列普通模拟通道 YT 波形，数组下标 `j` 从 0 开始：

```text
t[j] = XZERO + j * XINCR
v[j] = (raw[j] - YOFF) * YMULT + YZERO
```

- `raw[j]` 是按实际编码、符号及字节序解码后的数值，不是伏特。
- 时间公式按本系列 `XZERO` 定义直接从第一个传输点起算；`PT_OFF` 为 0。切换其他系列仪器时需重新核对，不能直接套用。
- 电压完整公式见 `WFMInpre:YMUlt/YOFf/YZEro`，手册 `2-956` 至 `2-959`（PDF 986-989）；`WFMOutpre:YMUlt/YOFf/YZEro` 明确引用这些换算说明。
- 手册 `2-101` 的演示给出 `Y = YZERO + YMULT * raw` 简式；只有 `YOFF = 0` 时才与完整公式相同，实现中应保留 `YOFF`。
- 若 YUNIT 不是 `V`，换算结果使用对应单位；不能强制标注为电压。

## 6. 二进制响应解析

`HEADer OFF` 且采用二进制编码时，`CURVe?` 的响应结构为：

```text
#<d><长度字段><payload><LF>
```

- `<d>` 表示后续长度字段的字符数，长度字段的十进制数值是 payload 字节数。
- 例如 `#520000` 表示后面有 20000 字节 payload。若每点 2 字节，则为 10000 个点。
- 先读 `#` 和长度位数，再读完整长度字段，最后循环接收精确长度的 payload，并消费尾部消息终止符。
- payload 可以包含 `0x0A` / `0x0D`，不能用换行分割 payload，不能对整个响应做文本解码或 `strip()`。
- 校验 `payload 字节数 = NR_PT × BYT_NR`，并核对格式为 `RI`、字节序与解码器一致、`PT_FMT = Y`。不一致时本轮数据作废。
- `RIBinary + WIDth 2` 对应有符号大端 16 位整数（例如 NumPy 类型 `>i2`）；`SRIbinary + WIDth 2` 对应 `<i2`。先转成浮点数组再做电压换算。
- `HEADer ON` 会在块前带上 `:CURVE` 等文本；本文解析流程以 `HEADer OFF` 为前提。

## 7. 内置测量指令（辅助核对）

平顶起伏、顶部倾斜及平顶覆盖率应由电脑对原始波形计算。下面的内置测量可用于日志及交叉核对，须在本次采集完成后执行。

手册依据：`2-421` 至 `2-431`（PDF 451-461）、`2-445` 至 `2-450`（PDF 475-480）。

### 7.1 测量源、范围和参考电平

```scpi
MEASUrement:IMMed:SOUrce1 CH2
MEASUrement:GATing OFF
MEASUrement:METHod AUTO
MEASUrement:REFLevel:METHod PERCent
MEASUrement:REFLevel:PERCent:LOW 10
MEASUrement:REFLevel:PERCent:HIGH 90
MEASUrement:REFLevel:PERCent:MID1 50
MEASUrement:REFLevel:PERCent:MID2 50
```

`GATing OFF` 使用整条记录，避免沿用操作者此前的光标/屏幕门控。LOW/HIGH 定义 10%-90% 边沿测量阈值，MID 定义中间参考阈值；高低电平的识别方法与这些百分比设置是两类配置。

### 7.2 每次选择类型，再读取数值

例如读取正脉宽：

```scpi
MEASUrement:IMMed:TYPe PWIdth
MEASUrement:IMMed:VALue?
```

| `MEASUrement:IMMed:TYPe` 的参数 | 含义 | 常用单位 |
| --- | --- | --- |
| `PWIdth` | 正脉冲宽度，按中间参考电平计算 | s |
| `RISe` / `FALL` | 上升 / 下降时间，按 LOW/HIGH 参考电平计算 | s |
| `AMPlitude` | 高电平减低电平 | V |
| `HIGH` / `LOW` | 顶部 / 基线参考电平 | V |
| `MAXimum` / `MINImum` | 全记录或门控区间的最大 / 最小值 | V |
| `PK2Pk` | 最大值减最小值 | V |
| `POVershoot` / `NOVershoot` | 正 / 负过冲 | % |
| `FREQuency` / `PERIod` | 首个完整周期的频率 / 周期 | Hz / s |

可用 `MEASUrement:IMMed:UNIts?` 查询实际单位。返回值常用科学计数法，例如 `9.273E-8` 秒即 `92.73 ns`。

注意：

- 只截取一个脉冲的短时间窗口可能没有完整重复周期，频率测量会无效；不能据此判断脉冲板没有输出。需要验频时，另采覆盖重复周期的长时间窗口。
- 手册列有 `9.9000E+37`、`9.91E+37` 等无效测量哨兵值，它们不是正常读数，也不是程序语言的 NaN。应结合单位、合理物理范围和错误队列拒绝此类值。
- `STDdev` 在本手册中是直方图相关测量，不能直接当作当前脉冲顶部的标准差。顶部波动应在电脑端选定平顶区间后计算。
- `AMPlitude` 与 `PK2Pk` 含义不同；脉冲板设置的脉宽与示波器 50% 电平实测脉宽，也应按实际输出标定关系比较。

## 8. 错误诊断与退出

| 指令 | 作用 | 手册页（PDF 页） |
| --- | --- | --- |
| `*IDN?` | 查询厂商、型号、序列号、固件等识别信息 | `2-350`（380） |
| `HEADer OFF` / `VERBose ON` | 设置普通响应格式 | `2-337`（367）、`2-935`（965） |
| `*CLS` | 清除事件队列和相关状态寄存器；不作为通用接收缓冲区清理方法 | `2-236`（266） |
| `*ESR?` | 读取并清除标准事件状态寄存器，同时使对应事件可读取 | `2-304`（334） |
| `ALLEv?` | 读取全部可读事件及文本，并移出事件队列 | `2-144` 至 `2-145`（174-175） |
| `EVMsg?` | 逐个读取事件码及文本，读取后移出队列 | `2-316`（346） |

诊断时先完整读取 `*ESR?`，随后读取 `ALLEv?` 并记录原始响应；顺序依据手册 `3-5`（PDF 1015）。不要先 `*CLS` 再查询，否则会清掉待诊断的错误，也不要反复读 `*ESR?` 却不消费对应事件。

正常停止整定时发送 `ACQuire:STATE STOP`；如需恢复人工连续观察，发送 `ACQuire:STOPAfter RUNSTop` 和 `ACQuire:STATE RUN`。停止示波器采集只停止数据获取，脉冲板和激光器输出的停止须由各自控制流程处理。

## 9. 实机联调最小检查

1. `*IDN?` 返回实际型号，Socket 协议为 `NONE`，命令终止及文本响应解析正常。
2. 确认 CH2、触发源、输入阻抗、探头配置及量程与接线一致；更换通道时同步更新所有通道相关配置。
3. 固定一组脉冲板参数，完成单次采集并确认同步成功；断开信号时能超时退出，不能沿用旧波形。
4. 核对二进制长度、点数、字节序及换算结果，电脑上的基线、顶部幅度、脉宽与示波器显示对应。
5. 改变一次量程或垂直位置后重新读取前导参数，确认换算仍正确，尤其检查非零 `YOFF` 的情况。
6. 修改 y 参数后采集到新波形；无触发、取消、通信中断和异常读数均不能被当作整定成功。
